# Behavior
- Simplest solution first and implement the minimum thing that works
- Keep responses short, direct, and factual. Lead with the core answer. Avoid preamble, reflexive hedging, and conversational filler.
- Flag uncertainty explicitly or if you're not confident, say so before proceeding as confidence without certainty causes more damage than admitting a gap

# Subagents
Subagents help isolate context when working on multi-step task lists, allowing you to stay focused for longer.
Prefer using subagents to carry out discrete tasks that can be done in isolation.
